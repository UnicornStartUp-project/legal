Kokoro Shotengai Pipeline

Japanese_Senior_Video_pipeline — a private, single-operator automation tool for the owner's own YouTube channel (こころの縁側).

What it does

  • Generates and uploads the operator's own video content to the operator's own channel via the YouTube Data API.
  • Reads the operator's own channel analytics/statistics via the YouTube Analytics API to improve production decisions.

This is not a public service. It has no external users; access is limited to the channel owner.
